# 💕 Coração

Um pequeno projeto feito com HTML, CSS e JavaScript para criar uma experiência especial e personalizada.

A ideia do projeto é simples:
uma tela protegida por senha que revela uma animação em formato de coração com o nome “Emily” aparecendo ao centro através de partículas e fogos animados.

---

## ✨ Funcionalidades

* Tela de autenticação personalizada
* Sistema simples de nome + senha
* Animação de partículas em Canvas
* Coração gerado matematicamente
* Nome aparecendo com efeito glow
* Botão para reiniciar a animação
* Interface responsiva
* Visual minimalista e romântico

---

## 🛠 Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript (Vanilla JS)
* Canvas API

---

## 📸 Preview

* Login secreto
* Efeito de foguetes formando um coração
* Nome surgindo com brilho ao final da animação

## 🔐 Personalização

Você pode alterar o nome e a senha diretamente no JavaScript:

```js
const ALLOWED_NAME = 'emily';
const SECRET_PASS = '1234';
```

Também é possível:

* mudar cores
* trocar fontes
* adicionar músicas
* inserir fotos
* criar novas animações
